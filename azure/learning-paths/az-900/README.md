# Microsoft Azure Fundamentals (AZ-900)

## Overview

Esta ruta de aprendizaje está basada en la certificación **Microsoft Azure Fundamentals (AZ-900)**, orientada al desarrollo de competencias relacionadas con los conceptos fundamentales de computación en la nube, los servicios principales de Microsoft Azure y los principios utilizados en entornos Cloud empresariales.

Su propósito es proporcionar una base sólida sobre la plataforma Microsoft Azure y preparar el camino para certificaciones de nivel asociado y especializado.

---

## Objective

El objetivo de esta ruta de aprendizaje es desarrollar competencias relacionadas con:

- Cloud Computing Fundamentals.
- Microsoft Azure Fundamentals.
- Core Azure Services.
- Cloud Security.
- Cloud Governance.
- Azure Best Practices.
