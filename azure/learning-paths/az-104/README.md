# Microsoft Azure Administrator (AZ-104)

## Overview

Esta ruta de aprendizaje está basada en la certificación **Microsoft Azure Administrator (AZ-104)**, orientada al desarrollo de competencias relacionadas con la administración, implementación, monitoreo y mantenimiento de recursos e infraestructura en Microsoft Azure.

Su propósito es desarrollar habilidades prácticas para administrar servicios Cloud utilizados en entornos empresariales.

---

## Objective

El objetivo de esta ruta de aprendizaje es desarrollar competencias relacionadas con:

- Azure Administration.
- Identity Management.
- Compute Services.
- Virtual Networking.
- Storage Administration.
- Resource Management.
