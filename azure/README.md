# Azure

## Overview

Azure es un dominio enfocado en el aprendizaje, implementación y administración de servicios en la plataforma Microsoft Azure, proporcionando conocimientos relacionados con infraestructura en la nube, servicios de plataforma, soluciones empresariales y buenas prácticas utilizadas en entornos Cloud.

Este dominio reúne documentación técnica, laboratorios, rutas de aprendizaje y recursos orientados al desarrollo de competencias relacionadas con tecnologías Microsoft Azure.

---

## Purpose

El propósito de este dominio es desarrollar competencias relacionadas con:

- Cloud Fundamentals.
- Azure Infrastructure.
- Azure Administration.
- Cloud Services.
- Identity Management.
- Cloud Best Practices.
